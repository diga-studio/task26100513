# task26100513

可增量更新的 ItemCF 邻居索引（调整余弦相似度），纯 Python、零依赖、状态全在内存。

## 使用

```python
from itemcf import ItemCFIndex

index = ItemCFIndex()

# 1) 全量构建：每条记录为 (user_id, item_id, rating)，rating 为 1..5 的整数
index.build([(1, 10, 5), (1, 11, 4), (2, 10, 1), (2, 11, 2)])

# 2) 增量变更：(user_id, item_id, rating)；rating 为 None 表示删除该评分。
#    每批的 (user_id, item_id) 键必须唯一；可引入新用户、新物品。
#    调用返回时整批已生效。
index.apply([(2, 11, 5), (3, 10, 4), (1, 11, None)])

# 3) 查询：返回该物品最多 50 个邻居的 [(item_id, score), ...]，
#    按分数降序、item_id 升序；不含自身；不存在的物品返回 []。
index.neighbors(10)   # -> [(11, 0.5938522968), ...]
```

## 相似度定义

- `c(u, i) = rating(u, i) - mean(u 的全部评分)`，未评分位置为 0。
- `sim(i, j) = Σ_u c(u,i)·c(u,j) / sqrt(Σ_u c(u,i)² · Σ_u c(u,j)²)`，
  分母覆盖各自全部评分用户，不限共同评分用户。
- 分数按 `round(score, 10)` 量化，仅保留正分；零范数物品没有邻居，
  也不会成为别人的邻居。

## 实现要点

- 用户均值是分母不超过 30 的有理数，所有点积/范数都以 `SCALE²` 缩放的
  整数精确累积（`SCALE = lcm(1..30)`，出现更多评分的用户时自动重缩放），
  因此增量更新的结果与从头构建逐位一致，浮点误差不会跨批累积。
- `apply` 只撤销/重加被修改用户的贡献，并只刷新"点积或端点范数实际
  变化"的物品对，绝不遍历未变更用户或无关物品对。
- 每个物品维护按 `(-score, item_id)` 排序的邻居列表（`bisect` 维护），
  `neighbors` 只是取前 50 条切片，工作量与返回条数成正比。
- 存储只包含当前评分、当前实际共现对（含共现计数，计数归零即删除）
  和当前正分邻居，随历史更新次数不增长。

