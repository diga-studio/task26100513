## ItemCF 增量邻居索引

纯内存、串行调用的 ItemCF 邻居索引，相似度为调整余弦（按用户均值中心化），
`apply` 增量维护，不从全量评分重训。

### 使用

```python
from itemcf import ItemCFIndex

index = ItemCFIndex()

# 构建：每条为 (user_id, item_id, rating)，rating 为 1..5 的整数
index.build([(1, 10, 5), (1, 11, 1), (2, 10, 4), (2, 12, 5)])

# 增量变更：rating 为 None 表示删除该评分；同一批内 (user, item) 键唯一
index.apply([(1, 11, None), (3, 10, 5), (3, 12, 4)])

# 查询：返回最多 50 个 (item_id, similarity)，按分数降序、item_id 升序
neighbors = index.neighbors(10)   # 不存在的物品返回 []
```

### 相似度定义

- `c(u, i) = rating(u, i) - mean(u)`，`mean(u)` 为该用户当前全部评分的均值。
- `sim(i, j) = Σ_u c(u,i)·c(u,j) / sqrt(Σ_u c(u,i)² · Σ_u c(u,j)²)`，
  分母取两列各自全部评分用户，不限共同评分用户。
- 分数按 `round(score, 10)` 量化，仅保留正分；零范数物品没有邻居，
  也不会成为别人的邻居；无共同评分用户的物品对不互为邻居。

### 实现要点

- 状态：用户评分、物品范数、共现对的分子与共现计数、每个物品全部共现对的
  量化相似度、每个物品预计算的 Top-50 榜单。存储随当前评分数与实际共现对数
  增长，共现计数归零的对会被删除。
- `apply` 只遍历本批被修改的用户：重算这些用户相关物品的范数增量与共现对
  分子增量，再重估受影响物品（分子变化的共现对两端、范数变化物品的全部共现
  邻居）的相似度并重建其 Top-50，不扫描未变更用户与无关物品。
- `neighbors` 直接返回预计算榜单，工作量与返回条数成正比。
- `index.stats` 与 `index.last_dirty_items` 暴露访问计数，供测试验证
  增量更新未越界扫描。
